# Project conventions

- Use Russian for visitor copy and documentation.
- Keep the existing React / TypeScript / Vinext stack.
- Run `npx tsc --noEmit` and `npm run build` after implementation changes.
- Start local preview with `npm run dev` on port 5173.
- Respect reduced motion in CSS and Morphicons.
- Preserve verified clinic contact information. Do not invent prices, testimonials or credentials.
- Deployment is on hold until the user supplies server details.
