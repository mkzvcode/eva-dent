# Ева Дент

Лендинг стоматологии в Копейске. React 19, TypeScript, Vinext/Vite, Morphicons + Lucide.

**Демо:** запустить локально (см. ниже) — публичного адреса пока нет, деплой в процессе.

## Локальный запуск

Требуется Node.js 22.13+.

```powershell
cd D:\Project\Codex\LandingMKZV\eva-dent
npm ci
npm run dev
```

Открыть http://localhost:5173/.

```powershell
npx tsc --noEmit
npm run build
```

## Структура

- `app/content.ts` — все тексты, цены, врачи, отзывы и контакты. Правки контента — только здесь.
- `app/page.tsx` — семантическая разметка секций (серверный компонент).
- `app/interactive.tsx` — клиентские части: шапка со scrollspy, мобильное меню, карточки услуг, FAQ, слайдер отзывов, нижняя панель на телефоне, появление блоков.
- `app/icons.tsx` — иконки. Lucide + свои стоматологические пиктограммы на сетке 24×24; Morphicons морфит их при наведении.
- `app/schema.ts` — микроразметка Schema.org (JSON-LD): `Dentist`/`MedicalClinic`, `WebSite`, `FAQPage`.
- `app/layout.tsx` — метаданные, Open Graph, viewport, подключение шрифтов.
- `app/globals.css` — дизайн-система и адаптив.
- `public/images` — фото клиники в WebP, OG-картинка, волнистая надпись.

## Дизайн-система

- Палитра: Linen `#FFEDE3`, Tangelo `#FB4D00`, Chocolate `#49261D`, Botticelli `#CAE7F7`. Оранжевый совпадает с логотипом клиники. Tangelo используется только для заливок и крупного текста; для кнопок с белым текстом — `#D93F00` (контраст 4.5:1).
- Шрифты: Unbounded (заголовки) и Manrope (текст), оба с кириллицей. Подключены локально через `@fontsource-variable`, без запросов к Google Fonts.
- Референсы: пилюли навигации и круглая кнопка с текстом по окружности, заголовки секций с линией и номером, бегущая строка с размытым «эхом», волнистая надпись «УЛЫБАЙТЕСЬ», зерно бумаги.
- Надпись `public/images/smile-wave.svg` сгенерирована из контуров Unbounded со синусоидальным смещением. Это статичный SVG, поэтому во всех браузерах он выглядит одинаково.
- Карта в контактах — встроенный виджет Яндекс Карт (`map-widget/v1`, без API-ключа) на координатах клиники, но со своей меткой поверх: стандартный красный пин отключён (в URL нет `pt`), вместо него — фирменный маркер в цветах сайта с подписью адреса (`.map-pin*` в `app/globals.css`, разметка в `app/page.tsx`). Карту можно двигать и приближать — маркер декоративный, поверх неё, `pointer-events: none`.

## Адаптив и кроссбраузерность

- Контрольные ширины: 320, 375, 768, 1024, 1440 px и больше; горизонтальной прокрутки нет.
- На экранах до 1023 px — бургер-меню и нижняя панель «Позвонить / Маршрут» с учётом safe-area на iPhone.
- Hover-эффекты включаются только на устройствах с мышью (`@media (hover: hover)`).
- Префиксы для Safari: `-webkit-backdrop-filter`, `-webkit-sticky`, `-webkit-clip-path`, `-webkit-hyphens`.
- `prefers-reduced-motion`: бегущая строка, вращение кнопки, появление блоков и морфинг иконок отключаются.

## Контент и источники

Сведения сверены с https://evadent74.ru/ (главная, «Специалисты», «Отзывы», «О компании», «Возврат НДФЛ», прайс услуг) 28.09.2026. Фото кабинета, зоны ожидания, входа, главного врача и приёма взяты с сайта клиники. Цены «от» — из опубликованного прайса, с пометкой даты. Отзывы — с сайта клиники, сокращения отмечены «…».

Перед публикацией:

1. Согласовать с клиникой тексты, фото, цены и блок отзывов. Для медицинской рекламы действуют ограничения ст. 24 закона «О рекламе» на отзывы с благодарностями.
2. Поменять `siteUrl` в `app/content.ts` на адрес, по которому будет доступен сайт (нужно для превью в мессенджерах).
3. Запись ведёт на звонок; онлайн-форма не подключена.
